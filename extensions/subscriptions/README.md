# Folyn 订阅

在当前 Vault 中订阅博客和技术网站，发现新文章、纯净阅读、按需全文翻译，并保存为可编辑的 Markdown。插件为 trusted tier，复用宿主 React 和 AI 模型配置。

0.5.0新增「添加单篇文章」：来源栏标题提供拉取图标，粘贴一篇文章或网页链接，提取并预览正文后加入当前 Vault 阅读，不创建订阅、不定时刷新。单篇文章归入「保留文章」，与订阅文章同样支持已读、收藏、翻译、保存与伴读。正文提取识别微信公众号等平台的隐藏正文容器（`#js_content`），静态页面即可读取，无需动态渲染。并排伴读围绕读懂、联系、应用进行流式追问，直接记录自己的想法，主动加入当前Vault笔记，再经可编辑预览新建或追加笔记。见[学习能力与验收边界](docs/learning-acceptance.md)。

可运行`pnpm prototype:learning`，打开[并排伴读原型](http://127.0.0.1:4178/?learning-prototype=1&sample=1&variant=A)。历史方案可添加`compare=1`查看。仅使用内存数据与模拟AI，不进入安装包；[体验说明](docs/learning-prototype-notes.md)。

## 当前交付

- 阅读工具条提供书本图标伴读入口，保留悬停提示与无障碍名称；左侧栏底部仅保留设置；右侧以「讨论 / 笔记」切换，首次将读懂、联系、应用三个紧凑问题入口与输入框放在一起，点击只填入并聚焦，再显式发送。历史直接从标题下拉切换，模型直接在输入框工具栏选择，参考与回答指引按需展开；回答下可「写下我的理解」或「摘到笔记」，「保存笔记…」进入正式文件预览。正文支持划选追问/记想法，复用Folyn模型配置进行流式多轮讨论。学习记录、材料快照、草稿按Vault独立恢复；切换文章不会自动改变讨论材料，清缓存和取消订阅保留学习内容。
- 整理笔记前可编辑预览并保留来源；新建采用禁止覆盖的原子创建，追加先核对笔记快照，再通过原生编辑器的一笔可撤销操作写入，保留未保存修改并遵循编辑器保存设置。

- 三栏工作区、可调栏宽、一个来源归入多个分组、全部/未读/收藏/已保存/保留文章视图。
- RSS / Atom / JSON Feed、静态文章列表、JSON-LD 与常见页面状态数据、robots 声明的网站地图；VuePress/VitePress等文档站优先读取本站文档及网站地图，目录范围在刷新时保留；静态读取无结果时使用隔离网页渲染，支持脚本生成的公开文章列表和正文。
- 添加前预览真实条目和正文；通过示例文章、候选列表、可读正文范围预览辅助识别。测试成功后才更新来源配置。
- 当前 Vault 的定时/手动刷新、每次最多 3 页、带游标的连续历史回溯、渐进列表、身份去重、阅读位置、收藏与已读状态。
- Readability 正文提取、DOMPurify 安全阅读、代码/表格/MathML 及公式 Markdown 转换；统一代码块结构、保留换行缩进，清理网站 CODE/语言工具栏，明暗主题语法高亮；旧正文缓存显示时同样修复。
- 打开时缓存正文与图片；按源自动下载后续新文章；现有文章显式下载；缓存清理保护收藏和正式文件。
- 原文/译文/双语阅读；模型与目标语言均支持下拉选择，选择按 Vault 保存，目标语言支持中文、English、日本語、Español、Deutsch、Français。首次调用展示模型和发送范围，翻译不写入宿主聊天历史。普通文章一次全文请求，超长正文才沿自然段落分成约4.8万字符的大块，共享2路并发；模型直接返回 Markdown、普通文本或 HTML，不要求 block/section、JSON 或对应原文结构。译文通过增量 DOM 更新实时展示并整体缓存，已加载图片保持原节点，文字追加时不会整篇重建图片；取消/中断保留已返回内容并注明未完成，恢复时重译未完成的大块。代码/公式/图片使用可选资源标记保护，模型未回传标记不会导致译文拒收。双语模式先展示整篇译文，再展示完整原文；旧逐段缓存仍可阅读，失败旧缓存重试时自动升级。
- 原文/译文/双语 Markdown 保存、独立图片附件、元信息、部分翻译或缺图的明确确认、重复保存保护和关联文件打开。
- 固定 Vault 的异步任务和文件会话，返回原 Vault 前等待旧任务写入结束，避免迟到结果污染重载的状态。

## 依赖的 Folyn 宿主更新

本次同时修改了同级 `folyn` 仓库的 SDK、桌面扩展宿主和 Rust 原生接口。旧宿主缺少 `api.subscriptions`，插件会明确提示需要更新，不能只安装 zip 后宣称功能可用。

宿主更新提供：

- 真实 Vault 生命周期、固定目录的会话、原子且禁止覆盖的文件创建。
- `permissions.subscriptions: { vault: true, network: true, render: true }` 显式权限，仅批准并启用的 trusted 扩展可用。
- 有超时/大小限制、重定向后重新校验公网目的地的网页及图片下载；兼容 gzip/deflate/brotli 和常见字符编码。
- 公开网站的隔离动态渲染：临时无痕容器、不复用登录 Cookie、不向网页开放宿主接口，单任务与约28秒超时。浏览器请求使用系统代理；直接 HTTP 仍使用固定公网 IP，不读取系统代理。
- 图片直连发生连接错误或返回403/429时，在已授权 `network` 和 `render` 的条件下使用隔离浏览器兜底。返回原始图片字节与响应格式，保留动图；任务有排队、大小与超时限制，停用插件时取消。此修复需要更新并重启 Folyn 宿主，单独重装插件 ZIP 不会替换原生下载器。
- 文件移动/删除事件、Activity Bar 未读数、AI 配置和 Vault 页面导航。
- `ai.chat({ persistHistory: false })` 无历史请求。伴读由插件显式携带当前学习记录的有限历史，使用独立请求ID，不混入宿主全局聊天。
- 0.4.0新增`chooseNotes`、`readNote`、`appendNote`，只选择当前Vault的Markdown；读取未保存缓冲区，追加有两次内容核对、正确编辑器实例等待和撤销隔离。对应[learning-host.patch](docs/learning-host.patch)已应用到同级Folyn仓库，不要重复应用；使用前需更新并重启该宿主。旧宿主仍可进行伴读、直接记录和新建笔记，选择已有笔记及追加入口会提示需要更新。

当前宿主已实现的本地与 GitHub Vault 都使用物理目录，均可接入；宿主尚未实现的 S3/WebDAV provider 不在本次承诺内。

宿主改动的可审阅补丁见 [host-integration.patch](docs/host-integration.patch)。本次会话中已将这些改动应用到同级仓库，不要重复应用。宿主已完成定向测试、原生模块编译检查及独立 Tauri/Wry 渲染运行检查；尚未完成完整 Folyn 安装后的端到端验收，详见验收记录。

## 构建与本地安装

要求 Node >=20，建议使用当前 Node 25；SDK 本地依赖位置为 `../../../folyn/packages/extension-sdk`。

```sh
pnpm install --frozen-lockfile
pnpm typecheck
pnpm test
pnpm build
pnpm package
```

`dist/` 是可安装目录，`dist/manifest.json` 的 main 为 `index.js`。在包含本次宿主更新的 Folyn 中打开 **设置 → 插件 → 从文件夹安装**，选择本项目 `dist/`，按宿主流程批准权限。切换到「订阅」工作区，在一个测试 Vault 中添加网站。

`folyn-subscriptions.zip` 只含安装文件。当前发布版本为 **0.0.1**，可从 [GitHub Release](https://github.com/linyimin0812/folyn-extensions/releases/tag/folyn-subscriptions-0.0.1) 下载。**需使用包含上述订阅宿主接口的 Folyn；旧版宿主无法运行。**添加订阅和来源设置中可点击标签选择多个分组，并直接新建分组；删除一个分组会保留来源的其他归属和文章。不选择分组的来源显示在「未分组」。已有单分组数据会自动保留为对应的多分组归属。

0.3.5完成体验收尾：设置、来源与分组提交失败时保留弹窗输入并回滚；刷新最新文章与加载历史分开，历史到底不会锁住后续刷新。添加订阅提交索引与预览正文后即完成，图片在后台缓存；中断后恢复为部分离线。来源批量下载与保存弹窗共用只补缺图的策略，保存弹窗原位显示进度和结果。搜索空态支持清空搜索；方向键跨越第40篇会加载下一批并保持焦点。图片支持键盘打开、缩放/100%/适应窗口/方向键移动/拖动和关闭，使用原生dialog及Tab循环，明暗主题和窄窗口保持可操作。详见[逐项验收](docs/experience-optimization-acceptance.md)。

左侧分组的箭头、标签与数量合并为整行折叠按钮，支持点击整行以及Enter/Space收起或展开，右侧编辑按钮独立操作。0.3.7移除额外的「分组文章」入口，展开后直接显示订阅源。

完成与操作提示统一使用顶部居中的紧凑 message 浮层，单行高度36px，使用12px文字、轻量状态图标、浅色状态背景和细边框，配色跟随页面明暗主题，不占用页面布局；成功和普通提示自动消失，错误可手动关闭，鼠标悬停或键盘聚焦时暂停计时。原生弹窗内也显示对应 message。来源设置的「内容与缓存」操作在弹窗内即时显示加载动效和结果，批量下载显示实际篇数进度；任务期间防止重复触发和冲突操作。重新识别后的测试也显示加载动效。

左栏分组标题和分区标签为13px，订阅名称为12px；添加图标仅在添加弹窗打开时高亮。添加/重新识别弹窗采用最高660px的稳定居中高度，正文区内部滚动；订阅偏好可在识别前填写，重试期间保留预览，失败后禁止导入未验证内容。

弹窗已统一重做：带说明的图标标题、按任务分区的表单、柔和填充控件、独立滚动正文和固定操作区。普通弹窗宽660px，分组、翻译及确认类宽460px；明暗主题和窄屏共用同一套组件。新建分组按需展开输入，减少常驻控件。

移除工作区顶部的订阅、未读数和 Vault 名称行；刷新全部、添加订阅与收起按钮集中在来源栏 header 中。左栏收起后隐藏刷新全部图标，保留展开、添加、系统视图及设置图标；展开来源栏后恢复刷新全部按钮。点击全部文章、未读、收藏或已保存图标会筛选并展开中间栏，左栏继续保持收起。文章列表收起后完全隐藏，不保留展开按钮或窄栏；点击左侧订阅行（含当前订阅）、系统视图或分组筛选，即可恢复原栏宽和对应列表。弹窗文字输入框、自定义下拉框与来源设置操作按钮统一为36px，使用单层1px焦点高亮。所有下拉菜单共用明暗主题、键盘导航和选中标记。来源设置支持修改并验证网址，保留已有文章；更新方式为互斥单选：仅刷新列表、自动下载新文章或暂停自动刷新与下载。来源栏与文章列表通过栏间细分隔线拖动调整宽度，支持键盘微调与各 Vault 的宽度记忆。包含此前紧凑界面、页面宽度及弹窗居中修复。插件 ID 为 `folyn-subscriptions`；本地 ZIP 安装器以文件名作为 ID，因此请保持该文件名，不要添加版本后缀。构建会先执行宿主共用的 manifest 校验器，拒绝没有连字符等无效 ID。

## 开发预览

```sh
pnpm dev --port 4178
```

先构建，再打开 `http://127.0.0.1:4178/?bundle=1&sample=1`，验收生产包。去掉 `bundle=1` 可检查源码热更新。预览包含宿主的横向 Flex 容器与基础样式重置，避免独立块布局掩盖集成问题。示例使用 3 个虚构来源和 12 篇中英文文章。追加 `&learning=1&stream=1` 可检查正式伴读、模拟流式回答及笔记交接；追加 `&theme=dark` 可验收深色样式。追加 `&imagecache=1` 可检查32张图片的计数、失败原因和重试（内存缓存及模拟响应）。追加 `&acquisition=1` 可检查动态网站识别、预览与导入流程（模拟渲染响应，非真实网络）。追加 `&experience=1` 可检查55篇列表、写入失败恢复和 `https://example.com/slow-images.xml` 的4.5秒慢图后台导入；追加 `&image=1&longimage=1` 检查长图查看、焦点和窄窗口。追加 `&latency=1500` 可模拟请求延迟，检查加载与进度反馈（只影响预览，不进入生产包）。顶部明确标注模拟数据，使用内存 Vault、示例站点与模拟 AI；不会访问真实 Vault、发送真实 AI 请求或持久化到磁盘。页面中的 Vault A/B 用于验证切换。预览入口 `test/preview.tsx` 不进入生产包。

## 存储与限制

数据位于 `~/.folyn/subscriptions/<vaultId>/subscriptions/`：`state.json` 保存元信息，`bodies/`、`images/`、`translations/` 保存版本化缓存；`learning/state.json` 独立保存学习记录、材料快照与草稿，缓存清理及取消订阅不删除它。插件卸载不主动移除这些数据。正式保存的文档及其 `assets/<保存ID>/` 附件不依赖缓存目录。

0.2.0 使用 schema 2，将来源分组存为数组。读取旧 schema 1 时转换原有单分组，下一次正常保存时写入新格式；转换保留文章、缓存及保存文件信息。

- 目标为公开博客与网站。动态渲染需要本次宿主更新及 `subscriptions.render` 授权；可执行页面脚本并有限滚动等待内容，不自动登录、解验证码、绕过付费墙或点击翻页。网页子资源由系统浏览器管理，无法逐项固定 DNS/IP；主页面与重定向仍验证公网目的地。
- 历史获取每次最多检查3个可识别的下一页，保留游标继续读取，每次导入最多20篇。Sitemap 每次最多6份地图、500个链接，初始标题来自网址，读取正文后补全；不承诺完整网站历史。
- PNG/JPEG/GIF/WebP/AVIF 图片不再限制张数，单张最多8 MB、每篇图片合计64 MB，2路并发。标题下显示已缓存/识别总数与处理进度；总数按正文识别出的不同图片地址计数。支持常见懒加载、picture/srcset，失败项显示原因与原图入口，可只重试未缓存图片并复用已有缓存。超限、格式不支持、防盗链或网络错误仍会导致部分离线可用。脚本图表、视频、SVG 等保留原网页入口。旧文章总数缺少懒加载图片时，可通过更多→重新获取正文与图片更新识别结果。
- 伴读每次最多12份材料，发送总计最多24,000字符材料、最近8,000字符讨论；本次实际发送范围可展开查看。未提供的笔记不会自动搜索或发送。学习数据损坏时保留原文件并停止覆盖，阅读仍可用。
- 取消伴读或翻译停止后续处理并丢弃当前请求的迟到结果；宿主现有 AI 传输没有中断接口，已发送请求可能仍由服务商处理。
- 配对文件重命名事件可更新路径，未配对的系统重命名只能在打开时检测文件不存在；不自动寻找或覆盖其他文件。
- 全文搜索仅覆盖已缓存正文；来源和条目查询都局限当前 Vault 与当前视图。

Turndown 使用浏览器 DOM，移除了只用于无 DOM Node 环境的 domino 依赖；单元测试使用 jsdom。依赖固定于 lockfile。

## 验证

参见 [验收记录](docs/acceptance.md) 与 [原始 PRD](docs/requirements.md)。模拟测试与真实抓取、宿主定向检查、原生运行验收分别记录，不将模拟翻译冒充真实模型质量验证。

0.5.1优化：各栏标题栏收紧到36px；正文窄表铺满可用宽度，宽表在自身容器内滚动。重复划选「记想法」直接进入已有笔记草稿，保留原内容、追加选段并聚焦末尾，不再自动展开参考卡片。

0.5.2：同一文章的连续摘录只记录一次来源链接；草稿已有参考来源时不再补写，保存预览按来源去重。译文选段仍保留语言标记，摘入AI回答时保留引用编号/标题并复用已有链接。

0.5.3：来源默认置于笔记末尾，连续摘录和继续写想法的光标位于来源前；保存预览再次整理来源位置。

笔记交互：后续摘录及摘入的 AI 建议自动与前一则想法以 Markdown 分隔线区分，来源保留在末尾；当前安装版本仍为 0.0.1。

划选后追问直接聚焦问题框，以“针对选段提问”标明上下文；参考材料与选段卡片不再自动展开，可按需点击查看。

选段追问：选段快照与每条问题绑定并随请求明确传给模型，聊天记录显示对应引用；重试使用原问题选段，后续划选不改写旧记录。
