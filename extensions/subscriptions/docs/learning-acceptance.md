# 0.5.1 并排伴读：实现与验收

日期：2026-10-21。用户选定A「并排伴读」后的首期正式实现。生产源码和宿主接口已经接入；真实模型质量、完整Folyn原生安装、系统文件选择器及进程重启仍需原生验收。

## 已实现

- 阅读工具条书本入口；正文划选「追问 / 记想法」。打开面板、编辑想法和选材料均不会自动调用AI。
- 阅读工具条显示书本图标伴读入口（保留提示与无障碍名称），左侧栏底部删除伴读入口，右侧为「讨论 / 笔记」。首次进入提供读懂、联系、应用三个紧凑行入口，紧接着是问题输入框；选择只填入问题并聚焦，再显式发送。键入时不折叠快捷问题，避免输入框移动。历史收进40px标题栏下拉，模型直接在输入框工具栏选择，参考与回答指引按需展开。笔记为独立书写区，保存始终在笔记工具栏；讨论区不再另设笔记底栏。默认370px，可拖动或用键盘调宽；窄窗口使用原生模态dialog，关闭后恢复阅读入口焦点。
- 复用Folyn已启用模型和流式调用。问题显式发送；回答实时显示，取消后保留部分内容并拒收迟到事件，支持重试原问题。Markdown安全渲染和代码高亮。
- 学习记录、问题草稿、材料快照、自己的想法及笔记关联按Vault保存。流式内容按有上限的间隔写入，输入失败保留并支持重试；损坏的学习JSON不阻止文章阅读，也不覆盖原文件。
- 明确加入/移除文章和所选Markdown笔记。切换阅读文章不会替换正在讨论的材料；用户选择「加入当前文章」或新开问题。历史回答保留实际发送的材料快照和范围，即使当前材料被移除仍可回看。
- 可直接记笔记；回答下「写下我的理解」切到自己的输入，「摘到笔记」明确复制回答及来源。草稿会自动保留，「保存笔记…」才进入正式Vault文件的预览；新建或追加前可继续编辑，补充未包含的参考来源。
- 新建笔记使用原子排他创建，重复提交不会覆盖用户编辑；已有笔记通过宿主读取未保存文本，核对预览、等待正确编辑器，再次核对，以一笔隔离的CodeMirror事务追加，可独立撤销。
- 流式更新只通知伴读面板，不连带刷新文章列表；旧回答HTML按内容复用，避免每个片段都重新解析此前全部回答。
- 清缓存、取消订阅保留学习记录、材料快照和正式笔记。Vault切换排空已授权的笔记写入，拒收旧模型回调；模块停用等待学习保存完成。

## 对话和数据归属

模型配置、凭据及传输由宿主负责。插件通过`ai.chat({persistHistory:false})`显式提供当前记录的有限历史，使用包含Vault、记录和请求ID的独立调用，避免宿主全局历史或其他记录串入。插件持久化学习讨论；首期不依赖每次新建宿主会话的`useSharedSession`，也不调用宿主尚未提供给扩展的Agent模式。

数据存于`.folyn/subscriptions/learning/state.json`，独立于可清理的正文、图片和译文目录。每次最多12份材料，材料正文与引句合计上限24,000字符，最近历史上限8,000字符；问题6,000字符、提问指引3,000字符，回答160,000字符。面板展示实际发送范围；截取的材料可展开检查，不声称读过未发送的全文。只发送明确加入的材料，不自动扫描Vault。

取消会立即停止接收及保存该请求的后续输出；当前宿主AI传输没有中断接口，已发请求仍可能由服务商处理。追加成功表示进入原生编辑器，并遵循宿主自动保存设置；UI明确提醒确认保存，不将编辑器事务冒充磁盘保存。
