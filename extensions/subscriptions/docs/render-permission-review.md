# 网页渲染权限审阅

0.3.0 安装清单新增权限：`permissions.subscriptions.render: true`。用户已于2026-10-18明确授权加入安装包；在 Folyn 中安装/更新时仍由宿主展示权限并批准。

用途：当公开博客/网站的直接 HTTP 获取、列表识别或正文提取失败时，调用 Folyn 宿主的隔离网页容器执行该网站脚本，等待内容生成，只返回当前公开页面的 DOM 快照。

范围与限制：

- 仅接受无账号密码的 HTTP(S) 地址，验证主页面及重定向的公网目的地。
- 网页运行在临时、无痕容器中，不复用用户浏览器登录 Cookie，不获得 Vault、文件、AI 或其他 Folyn 宿主接口访问权。
- 网页自身的脚本可能加载第三方资源；系统浏览器的资源网络请求无法像直接 HTTP 下载一样钉住 DNS/IP。
- 不弹出窗口，不下载文件，不自动提交登录，不解验证码；失败会明确显示原因。
- 同时最多一个渲染任务，约28秒超时，DOM快照上限8 MiB；完成、取消、停用均销毁容器并清理临时数据。
- 声明进入 ZIP 后仍须在 Folyn 安装/更新并批准扩展，才会得到对应宿主能力；不会由开发脚本直接授权用户的生产安装。

已完成的可审阅实现：宿主 `apps/desktop/src-tauri/src/subscription_render.rs`、SDK `ExtensionSubscriptions.render`、插件 `src/acquisition.ts`。原生独立测试已验证延迟生成内容、超时和取消清理；任务/接口检查使用临时夹具，不读取用户真实 Vault。
