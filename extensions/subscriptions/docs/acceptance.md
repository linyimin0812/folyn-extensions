## 原生验收门槛

必须用包含新增原生命令的 Folyn 重新编译并启动，然后从文件夹安装 `dist/`、由用户批准 trusted 权限。建议创建测试 Vault，完成 claude.dev 的添加、真实图片缓存、离线重开、切换 Vault 与 Markdown 打开。真实 AI 翻译需在披露模型后由用户确认，当前结果只验证模拟传输与缓存/排版逻辑，没有消耗真实模型额度。

用户已明确授权编译并进行原生验收。当前已有 Folyn 开发宿主运行，但原生界面工具按 bundle ID 连接超时、无法绑定开发二进制，原生操作与安装验收仍未完成。本记录不把源码、浏览器或定向检查等同于原生全部验收通过。
